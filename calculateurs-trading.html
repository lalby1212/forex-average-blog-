📖 Comment ça marche ?

Taille de Position : Calculée selon votre capital, votre risque % et la distance du stop loss

Valeur du Pip : Montant gagné/perdu par mouvement de 1 pip

Risque Réel : Montant maximum que vous allez perdre si le stop est touché

Ratio R:R : Profit potentiel divisé par perte potentielle (objectif: minimum 1:1, idéal 1:2 ou plus)

Formule : Taille Position = (Capital × Risque%) / (Stop Loss × Valeur Pip)

📖 Comment ça marche ?

Liquidation : Votre position ferme automatiquement quand votre marge tombe sous le seuil de maintenance

Marge Requise : Montant bloqué = Position Totale / Levier

Distance Liquidation : % de variation avant liquidation. Exemple: -15% = 15% baisse avant liquidation

Taux Maintenance : Crypto (5%), Forex (0.5%), dépend du broker

⚠️ DANGER : Distance < 5% = Très dangereux ! Fermez la position ou ajoutez marge

SAIN : Distance > 15% = Bon buffer de sécurité

📖 Comment ça marche ?

Exposition Totale : Somme de toutes vos positions (Position × Levier)

Marge Utilisée : Capital bloqué = Exposition / Levier

Marge Libre : Capital disponible pour nouvelles positions

% Utilisation : % du capital utilisé. Idéal < 50%

Ratio Expo/Capital : Exposition / Capital. Idéal < 2x pour traders modérés

SAIN : < 50% utilisation marge | MODÉRÉ : 50-80% | DANGEREUX : > 80%
